# Two-Sentence Horror

A two-sentence horror story entry for the make.fun bounty "Two-Sentence Horror". The program `main.py` writes one story to `/output/entry.txt` — a baby monitor whispering the narrator's name in their own voice, until it whispers the daughter's name and she answers from inside the walls.

> The baby monitor started whispering my name last Tuesday, in my own voice. This morning it whispered my daughter's name, and she answered from inside the walls.

Run it with `python3 main.py`. It asserts the entry is 1–400 characters, exactly two sentences (exactly two periods, no other sentence-ending punctuation), with no leading or trailing whitespace, then writes it with no trailing newline.
